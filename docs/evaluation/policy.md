# 評価の方針

UI を単純な総合点だけで評価しない。
評価軸と重要度は、対象プロダクト、画面、Experiment の目的に応じて変える。
最終判断は人間が行う。

## 評価軸

17 の軸の定義と判定の目安は [axes.md](axes.md) に定める。
Experiment ごとに軸と重みを選ぶ手順は [review.md](review.md) に定める。

## 複数観点のレビュー

AI による自己評価だけに頼らない。
designer、accessibility など異なる観点のレビューを独立に行う。
観点の定義、記録形式、まとめ方は [review.md](review.md) に定める。
判断は [evaluation framework の ADR](../decisions/2026-09-13-evaluation-framework.md) に残す。
