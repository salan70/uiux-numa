# 評価の方針

UI を単純な総合点だけで評価しない。
評価軸と重要度は、対象プロダクト、画面、Experiment の目的に応じて変える。
最終判断は人間が行う。

## 評価軸の候補

- visual hierarchy
- information density
- discoverability
- information architecture
- interaction clarity
- writing clarity
- motion appropriateness
- feedback quality
- consistency
- accessibility
- platform fit
- delight
- perceived performance
- localization robustness
- implementation cost
- maintainability
- brand fit

## 複数観点のレビュー

AI による自己評価だけに頼らない。
異なる観点のレビューを行える設計にする。

観点の例:

- designer
- UX / product reviewer
- UX writing reviewer
- accessibility reviewer
- platform reviewer
- interaction / motion reviewer
- implementation reviewer

各観点の基準、重み付け、結果の記録形式は後続 Issue「UI/UX evaluation framework」で決める。
