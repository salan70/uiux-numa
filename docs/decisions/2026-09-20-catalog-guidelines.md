# Catalog に方針を二次情報として載せる

- 状態: Accepted
- 日付: 2026-09-20
- 参照: [visual showcase ADR](2026-09-20-catalog-visual-showcase.md)、[見本帳へ絞る ADR](2026-09-19-catalog-artifacts-only.md)
- 更新: 規則の書式は [方針の書式 ADR](2026-09-20-guideline-format.md) が置き換えた。
- 更新: 公開実装は [topic-first ADR](2026-09-20-catalog-topic-first.md) で `/guidelines` と `/guidelines/:slug` として入れた。
- 更新: 画面での見せ方は [箱をやめる ADR](2026-09-21-catalog-guideline-plain-layout.md) と[規則の構造 ADR](2026-09-21-catalog-guideline-rule-structure.md) が置き換えた。節の見出しも英語にし、実験の出どころは正本にだけ残す。
- 更新: 「図版の正本は見本帳が持ち、規則からキーで参照する」は[対比の対 ADR](2026-09-21-catalog-guideline-contrast-pair.md) が取り消した。`- 図:` の項目と図版そのものを廃止した。

## 背景

Catalog は成果物の visual showcase と定めた。
成果物を触ることを優先し、原則や導入手順は主役にしない方針をとった。
一方で、成果物をどういう考えで作ったかは画面から読めない。
判断の根拠はリポジトリ内に散らばり、探す負担が大きい。
まとまった文書は原則候補の 3 件だけで、主題ごとの指針がなかった。

## 決定

- Catalog に「方針」のページを足し、ガイドラインを掲載する。
- ガイドラインは二次情報として扱い、成果物探索の邪魔をしない。
- 正本は `docs/guidelines/*.md` に置き、Catalog は glob で読む。
- 文書の単位は 1 文書 1 主題とし、中に規則を並べる。
- 規則はコアと Tips の 2 層に分ける。コアは主題の土台、Tips は個別の場面への適用とする。
- 文書名は英語にする。本文と規則は日本語で書く。
- 規則には意図と根拠、良い例、悪い例、出どころを必ず付ける。
- 出どころはリポジトリ内の実験と外部の出典に区別する。
- status は draft と adopted の 2 値とし、人間が採否を決める。
- Markdown の描画に依存を足さず、定めた書式を読む解析器を使う。
- 図版の正本は見本帳が持ち、規則からキーで参照する。

## 理由

方針を二次情報として載せると、判断の背景を確かめられる。
1 文書 1 主題にすると、利用者が関心のある主題から引ける。
良い例と悪い例を並べると、規則の意図が一読で伝わる。
出どころを分けると、実験で得た知見と一般的な出典を混同しない。
解析器を自前で持つことで、bundle 肥大化と表示の乱れを防げる。
規則を 2 層に分けると、主題の土台と個別の適用を読み分けられる。1 層のままでは、根本の規則と場面に紐づく規則が同じ強さで並ぶ。
文書名を英語にすると、面の名が短くなり一覧の形が揃う。CLAUDE.md の「文書は日本語で書く」に対する明示の例外として扱う。

## 却下した案

- 公開 Design System サイトに戻す: ドキュメントが主役になり、成果物探索とずれる。
- 1 規則 1 ファイルにする: 60 ファイルを超え、主題で束ねて読めなくなる。
- 自由な散文にする: 規則ごとの根拠が曖昧になり、検証に結び付かない。
- 外部依存を足す: bundle が増え、型付きデータとして扱えない。
- HTML を埋める: 正本が表示側の実装に縛られる。
- 規則を 1 層のままにする: 根本の規則と個別の規則が同じ強さで並び、どれが前提か読めない。
- 層を 3 つ以上にする: 層の境が曖昧になり、書き手が置き場に迷う。
- 文書名も日本語にする: 「タイポグラフィ」のような長い名で、ナビの一覧が折り返す。

## 影響

- `apps/catalog` へ載せる段階では URL を `/guidelines` にする。
- 調査や決定文書、Experiment 本文、原則候補は引き続き描画しない。
- `docs/layers.md` の Catalog 層に、方針を二次情報として載せる説明を足す。
- `skills/exploring-ui-variants/` の参照先に `docs/guidelines/` を足す。
- 画面には status、規則数、評価軸、判断者、判断日を出さない。正本の frontmatter と判断の節には残す。
- 先行実装は `experiments/catalog-editorial/variants/topic-first` で行う。
