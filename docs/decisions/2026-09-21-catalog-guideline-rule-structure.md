# 規則を bad / good の対に組み直し、行長の上限をやめる

- 状態: Accepted
- 日付: 2026-09-21
- 参照: [箱をやめる ADR](2026-09-21-catalog-guideline-plain-layout.md)、[方針を二次情報として載せる ADR](2026-09-20-catalog-guidelines.md)、[方針の書式 ADR](2026-09-20-guideline-format.md)
- 対象: `apps/catalog` の表示層のみ。`docs/guidelines/*.md` の書式は変えない。
- 更新: 規則の組み方と図版の扱いは[対比の対 ADR](2026-09-21-catalog-guideline-contrast-pair.md) が置き換えた。bad / good は 2 行ではなく左右の桁になり、図版は廃止した。

## 背景

箱をやめた画面を利用者が見て、次の指摘が出た。

- 本文が行長の上限で止まり、見出しの罫より内側で折り返していた。「横幅いっぱいまで広がってほしい」。
- 節の見出しだけが日本語で、ナビと文書名の英語と混じっていた。
- コアと Tips の直下にある層の説明文が読まれていなかった。
- 規則 1 件が 題名 → タグ → 図版 → 根拠 → bad / good → 例外 → 実験 の 7 ブロックに散らばり、
  `bad` が図版のラベルと例の行で 2 回出ていた。「構造的で、情報の優先順位や関係性とかを示したい」。
- 規則ごとの「実験」欄が読む助けになっていなかった。
- 全画面の末尾にあるフッター（リポジトリとライセンスへのリンク）が不要だった。

## 決定

- 規則の軸を bad / good の対にする。標本はどちらかの実例なので、対応する行の直下へ入れる。
  規則 1 件は 題名 → 分類 → 根拠 → bad / good（標本つき）→ 例外 → Source の順にする。
- 図版は独立した節をやめ、ラベルもキャプションも持たない標本にする。
  どちらの例かは差し込み先の行が示し、何が起きているかは規則の bad / good の文が説明する。
- 本文に行長の上限を置かない。桁の幅がそのまま行長になる。
- 方針画面の節見出しを英語にする（Purpose / Scope / Core / Tips / Checklist / Sources / Index）。本文は日本語のままにする。
- コアと Tips の層の説明文を出さない。
- 規則ごとの「実験」欄を画面から外す。正本の `実験:` は残す。
- フッターを全画面から外す。

## 理由

bad と good は規則の中で唯一の対である。
対を軸にすると、図版・文・例外が何に属しているかが位置で決まる。
標本を独立した節に置くと、どちらの例の図なのかを読み手が突き合わせることになり、`bad` の語も 2 回出ていた。
標本を行の下へ入れると、この突き合わせと重複がどちらも消える。
標本のキャプションは規則の bad / good の文とほぼ同じことを書いていたので、標本と一緒に落とせる。

行長の上限は読みやすさのための一般則だが、この画面では見出しの罫が桁いっぱいに引かれている。
本文だけが内側で折り返すと、罫の右端と本文の右端が合わず、版面が崩れて見える。
桁の幅は右の索引（16rem）が決めており、それ自体が上限として働く。

節の名を英語にすると、ナビ、文書名、節の 3 層で語が揃う。
文書名を英語にする判断（[方針を二次情報として載せる ADR](2026-09-20-catalog-guidelines.md)）の延長であり、本文は日本語のままにする。

層の説明文は、読み手が規則を読むのを 1 段遅らせるだけだった。
コアと Tips という名と、規則そのものの並びで層の違いは読める。

実験欄は「この規則がどの実験から出たか」を示すが、規則を使う人の判断は変わらない。
出どころを残す必要があるのは正本であって、画面ではない。

フッターのリポジトリとライセンスのリンクは、全画面の末尾に同じものが出ていた。
読み手が探す情報ではなく、版面の末尾を占めるだけだった。

## 却下した案

- 規則の左にラベルの桁を 1 本通す: どの行が何かは読めるが、`bad` の重複と図版の突き合わせが残る。
- 規則を畳んで一覧にする: 一覧性は最高になるが、規則を読むのに操作が 1 回増える。方針は読むための面である。
- リードだけ全幅にする: 見出しの罫と揃う範囲が広がるが、規則の中の長い文は内側で折り返したままになる。
- 右の索引をやめてさらに広げる: 桁は広がるが、規則の全体像を読みながら本文を追えなくなる。
- 層の説明文を残し、コアの分だけ消す: 左右で節の形が揃わなくなる。
- 実験欄を折りたたみにする: 画面から消える点は同じで、操作だけが増える。
- フッターを 1 行に縮める: 読み手が探す情報ではないので、短くしても占める位置は変わらない。

## 影響

- `foundation` と `module` の意味は画面から読めなくなる。語の定義は正本（`docs/guidelines/`）と
  [asset-composition-model ADR](2026-09-20-asset-composition-model.md) が持つ。
- 規則の「実験」は正本にだけ残る。画面から辿る道は無くなる。
- ライセンスとリポジトリへのリンクは画面から消える。リポジトリの README が持つ。
- `apps/catalog/src/components/figures.tsx` は、図版のコンポーネント（`FIGURE_COMPONENTS`）から
  bad / good の標本の対（`FIGURE_SPECIMENS`）へ形が変わった。キーの正本は変えていない。
- 画面の bad / good は縦に積まれる。横に並べた対比はできなくなる。
- `experiments/catalog-editorial/variants/topic-first` へは写さない。前の ADR と同じ扱いである。
