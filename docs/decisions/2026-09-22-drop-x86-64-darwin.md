# x86_64-darwin を対象外にする

- 状態: Accepted
- 日付: 2026-09-22
- 参照: [SVG 制作の実行基盤を決める](2026-09-18-svg-toolchain.md)、[SVGO に零長の subpath を残させる](2026-09-22-svgo-keeps-zero-length-subpaths.md)
- 対象: `flake.nix`

## 背景

`flake.nix` は resvg、svgo、oxfmt を `nixpkgs-unstable` から取る。
現在の lock は rev `eaad089`（Nixpkgs 26.11）である。

この rev は x86_64-darwin の対応を打ち切っている。
Intel Mac では `nix develop` が評価できず、devShell に入れない。
`catalog-ui-icons` はこの状態で作業したため、`nixpkgs-26.05-darwin` の一時 pin で代替した。
代替 pin の svgo 4.1.0 は零長の subpath を残し、正本 pin の svgo 4.0.1 は削除するという差があり、配布用 SVG が再現できなくなった（[零長 subpath の ADR](2026-09-22-svgo-keeps-zero-length-subpaths.md)）。

一時 pin は、環境が分かれたことを検証が検知できない形で成果物に入り込む。
どの system を対象にするかを決めていなかったことが原因である。

## 決定

x86_64-darwin を対象外にする。

`flake-utils.lib.eachDefaultSystem` をやめ、`eachSystem` に system を列挙する。
対象は aarch64-darwin、x86_64-linux、aarch64-linux の 3 つにする。

x86_64-darwin では devShell の出力自体が存在しなくなる。
nixpkgs の評価の途中で落ちる代わりに、対象外であることがそのまま出る。

動作を確認したのは aarch64-darwin だけである。
Linux 2 つは `eachDefaultSystem` の既定に含まれていたものをそのまま残す。
新たに対応を主張するものではない。

## 却下した案

- `nixpkgs-unstable` を `nixpkgs-26.05-darwin` へ差し替える: x86_64-darwin が戻り、svgo も 4.1.0 に戻る。ただし resvg、oxfmt、node、pnpm の版も同時に下がる。26.05 は x86_64-darwin に対応する最後の系列であり、次の系列でこの判断をやり直すことになる。対応を続ける判断を先送りするだけである。
- `eachDefaultSystem` のまま、対象外を文書にだけ書く: 文書は `nix develop` の失敗の場に出ない。Intel Mac で評価が落ちたとき、原因が対象外なのか壊れたのかを読み手が区別できない。
- x86_64-darwin 用に別の pin を分岐させる: system ごとにツールの版が変わる。`catalog-ui-icons` で起きた「環境によって成果物が変わる」問題をフレークに常設することになる。

## 影響

- Intel Mac では devShell に入れない。検証も制作もできない。
- 一時 pin による代替は行わない。環境が用意できないときは、用意できる環境で作業する。
- `catalog-ui-icons` の記録に残る「x86_64-darwin で作った」経緯は、この決定の前の状態である。記録は変更しない。
- Linux 2 つは未確認のまま残す。必要になった時点で確かめる。
