# 文書と Skill の読者を Opus 5.5 相当のモデルに絞る

- 状態: Accepted
- 日付: 2026-09-25
- 参照: [規約と記録の組み直し](2026-09-24-minimal-docs.md)、[CLAUDE.md](../../CLAUDE.md)、[skills/README.md](../../skills/README.md)

## 背景

CLAUDE.md、`docs/`、`skills/` の文書は、読者となるモデルを限定せずに書いていた。
そのため、一般知識の解説、言われなくても行う手順、規則の理由の散文、同じ内容の重複が残っていた。
利用者は Anthropic の Opus 5.5 とそれに相当するモデルに照準を合わせ、明示しないと結果が変わる記述だけを残すことを求めた。

## 決定

- 文書と Skill の読者は Opus 5.5 相当のモデルとする。言わなくても同じ結果になる説明は書かない。
- 残す記述は次に限る。リポジトリ固有の事実（パス、コマンド、値、形式）、機械検査される形式、利用者が複数の妥当な選択から決めた事項、実測で分かった落とし穴、既定の振る舞いを禁じる指示、判断の主体。
- 一般知識の解説、言われなくても行う手順、規則だけで一意に解釈できる理由、重複、明らかな規則の例示は削る。
- 対象は CLAUDE.md、`docs/`（`decisions/` と `principles/<slug>.md` を除く）、`skills/`、`tokens/*/README.md` とする。ADR、Experiment の README、原則候補は記録なので書き換えない。
- Guideline と Experiment の機械検査される形式は変えない。形式の中で記述を削る。
- Skill の参照 ID は、Experiment の README が引用しているものの番号を変えず、消した番号は欠番にする。

## 却下した案

- 対象を CLAUDE.md と Skill に限る: Guideline と `docs/` の規約も Skill から読まれ、同じ冗長さがある。
- 一般知識の解説を残して短くする: 短くしても読む量は残り、削る基準が「Opus 5.5 が知っているか」に戻る。
- Guideline の必須項目（良い例、悪い例）を任意にする: 解析器と Catalog の表示が変わり、人間が読む見本としての形が崩れる。
- ADR と Experiment の README も同じ基準で書き換える: 記録は判断当時の文脈を残すものであり、読者の想定で書き換えない。
- 対象モデルより弱いモデルへの配慮を残す: 二重の読者を想定すると、どの説明を削ってよいかが決まらない。

## 影響

- CLAUDE.md の「プロジェクト固有ルール」に読者の想定を 1 文で書く。
- 以後の文書と Skill の追加、改稿は同じ基準で書く。
- 参照 ID の欠番は、Experiment の README からの引用を保つためのものであり、詰めない。
