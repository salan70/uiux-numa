# 対象領域

uiux-numa は UI の視覚表現だけを対象にしない。
ユーザーがプロダクトを利用するときの体験を構成する要素を広く研究対象とする。
この分類は固定的な区分ではなく、Experiment や知見を整理するための基準として使う。

## UI / Visual

- visual design
- layout
- typography
- iconography
- logo / brand identity
- illustration / SVG
- color
- responsive / adaptive design
- design tokens
- data visualization

## UX / Structure

- information architecture
- navigation
- interaction design
- UX writing / content design
- forms / input UX
- onboarding / guidance
- states design
  - loading
  - empty
  - error
  - offline
  - disabled
  - success
  - skeleton

## Experience / Feedback

- animation / motion design
- transitions
- micro-interactions
- gesture
- hover / focus / selection
- sound
- haptics
- perceived performance
- optimistic UI などの体感速度改善

## Quality / Context

- accessibility
- localization / internationalization UX
- platform conventions
- usability
- consistency
- implementation cost
- maintainability

## 中核領域

次の 5 領域を中核として扱う。

- UX Writing / Content Design
- Information Architecture
- Interaction Design
- Animation / Motion
- Accessibility

## 対象プラットフォーム

Web、Web LT、SwiftUI、Flutter、スライドを想定する。
