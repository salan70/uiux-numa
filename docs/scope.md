# 対象領域

UI の視覚表現に限らず、プロダクトを利用するときの体験を構成する要素を対象にする。
項目名を kebab-case にしたものが Experiment の frontmatter `domains` の語彙である。

## UI / Visual

- visual design
- layout
- typography
- iconography
- logo / brand identity
- illustration / SVG
- color
- responsive / adaptive design
- design tokens
- data visualization

## UX / Structure

- information architecture
- navigation
- interaction design
- UX writing / content design
- forms / input UX
- onboarding / guidance
- states design
  - loading
  - empty
  - error
  - offline
  - disabled
  - success
  - skeleton

## Experience / Feedback

- animation / motion design
- transitions
- micro-interactions
- gesture
- hover / focus / selection
- sound
- haptics
- perceived performance
- optimistic UI などの体感速度改善

## Quality / Context

- accessibility
- localization / internationalization UX
- platform conventions
- usability
- consistency
- implementation cost
- maintainability

## 中核領域

- UX Writing / Content Design
- Information Architecture
- Interaction Design
- Animation / Motion
- Accessibility
