# UX / product レビュー: Catalog の visual direction

- 観点: UX / product
- 対象: precision-keyboard、quiet-hierarchy、playful-chroma
- 入力: README、variants/、docs/evaluation/axes.md
- 担当した軸: discoverability

## 判定

| 軸              | precision-keyboard                  | quiet-hierarchy          | playful-chroma                   |
| --------------- | ----------------------------------- | ------------------------ | -------------------------------- |
| discoverability | 良い: 検索とコマンドで 3 件へ即届く | 許容: 2 件目は下のリンク | 許容: カードは見える。凡例は無い |

## 観察

### precision-keyboard

- ⌘K でパレットが開く。一覧に絞り込み入力がある。
- トップ、一覧、詳細の 3 面がある。

### quiet-hierarchy

- 検索が無い。件数 3 では足りるが、本番の件数では不足しうる。
- ナビはトップと一覧だけである。

### playful-chroma

- 入口で 3 カードが並ぶ。棚は source まで一行で出す。
- role 色の意味は画面内で説明しない。

## 論点

- 本番件数が増えたとき、検索無しの静かなトップが持つか。
