## Problem

公開サイトの表示名を「UI/UX NUMA」へ変えたが、顔になる形がない。
[表示名の ADR](../../docs/decisions/2026-09-22-display-name-uiux-numa.md) は「ロゴの wordmark は本 ADR では決めない」「ロゴと favicon は未着手」を残した。

favicon は存在しない。
`apps/catalog/index.html` に `<link rel="icon">` がなく、`apps/catalog/public/` は `_redirects` だけである。
本番 `https://uiux.oda79.me/` はブラウザ既定の白紙アイコンで出ている。

サイドバー題字とホーム大見出しは、書体そのままの文字列である。
タブ、ブックマーク、共有先のように文字が使えない面で、このサイトを指す形がない。

## Target

Catalog を見る利用者と、リポジトリの作者自身を対象にする。
最も頻度が高い面はブラウザのタブ（16px）である。
次がサイドバー題字（20px 相当）、最も大きい面がホームの大見出し（42〜96px）である。

## Scope / Domains

対象はマーク 1 個と、その lockup の形式である。
domain は `logo-brand-identity`、`visual-design`、`accessibility`。
`iconography` は入れない。`logo-brand-identity` に topic が無いため、2 番目以降の domain が topic を決めてしまう。

variant で変えるのは、`nu-round` の骨格（丸い端点の nu）に対する「溶ける気配の出し方」だけである。
viewBox、live area、格子、字画、色数、丸い端点は melt 系の 6 案で共通にする。

比喩の系統と目指す印象は、制作前に利用者が決めた（2026-09-22、2026-09-23）。

- 比喩: 初回は「比較の 2 面」だった。3 案とも却下され、「沼」から連想される水や沼地の気配を少し入れることへ変えた。
- 比喩（第 3 世代）: 水の気配の 4 案も却下された。理由は「比喩が合わない」と「文字要素が欲しい」である。全案に文字（N、U、nu）を核として入れ、文字、有機的な沼の形、UI/UX の記号、抽象的な記号の 4 系統で作る。
- 比喩（第 4 世代）: 第 3 世代から利用者が `nu-arches` を方向として選んだ（2026-09-23）。その派生を作る。
- 比喩（第 5 世代）: 派生 6 案を見た利用者が、「溶けている」印象を軽く与えることと、全体を曲線で滑らかなテイストにすることを求めた（2026-09-23）。
- 印象: 実験的で動きがある。したがって非対称にする（`LOGO-03`）。
- 作図: 座標は数式から出す。体系、理論値、採用値、誤差を残す。

この順は [比喩は描き方より先に効く](../../docs/principles/metaphor-decides-before-style.md)（`candidate`）と、`crafting-svg` の手順 1 に従う。
削除した `class-doc-logo` は比喩をエージェントが選び、4 案とも却下された。

## Constraints

- `<text>`、`var()`、`aria-labelledby` を使わない。`role="img"` と最初の子 `<title>`、id は `part-<asset>-<role>`、色は `currentColor`（[SVG ツールチェーンの ADR](../../docs/decisions/2026-09-18-svg-toolchain.md)）。
- フォントの outline 化ツールは同 ADR で却下済みである。path の wordmark を作る場合、LINE Seed JP の複製ではなく独自の作図になる。
- SVG に色を書かない。差し替えは利用画面の CSS で `part-*` を上書きする。
- 白黒 1 色で設計し、反転と 16px で成立してから色を考える（`LOGO-07`）。
- 10 配色 × light / dark で成立させる。`sumi` の dark は `--cat-accent` が背景にほぼ溶けるため、前景に色を持たせるなら `--cat-accent-text` を使う。
- viewBox は `0 0 32 32`。favicon の基準が 32px である（`LOGO-07`）。
- Catalog には載せない。`domains` の先頭を `logo-brand-identity` にして topic を持たせない（[掲載しない Experiment の ADR](../../docs/decisions/2026-09-22-unlisted-experiments.md)）。

## Hypothesis

`nu-arches` の骨格を曲線と丸い端点で柔らかくし、重力で垂れる、ためる、広がるといった溶ける気配を 1 か所だけ足すと、16px でも nu の字として読めたまま、沼の粘りを軽く伝えられる。

## Variants

`nu-arches` と `nu-round` は基準として残す。melt 系の 6 案は、端点を丸めた `nu-round` の骨格から作る。

| ---------------- | -------------------------------------------------------------------------------- | ----------------------- | -------------------------- |

| `nu-round`       | 基準: 端点を丸めると柔らかくなる。melt 系の骨格                                  | 端点（丸）              | `variants/nu-round/`       |
| `melt-bulb`      | 下の端だけに液がたまると、重力で溶けていることが伝わる                           | 端がたまる              | `variants/melt-bulb/`      |
| `melt-drip`      | u の底から滴が 1 つ垂れると、字の形のまま溶けている途中に見える                  | 滴が垂れる              | `variants/melt-drip/`      |
| `melt-sag`       | 肩を平たく、底を下へ伸ばすと、要素を足さずに形そのものが垂れて見える             | 形が垂れる              | `variants/melt-sag/`       |
| `melt-flow`      | 直線をなくし曲線だけでつなぐと、固体ではなく流れる線に見える                     | 線が流れる              | `variants/melt-flow/`      |

### 造形のパラメータ

8 案で共通にする。

| 項目      | 値                | 理由                                                                 |
| --------- | ----------------- | -------------------------------------------------------------------- |
| viewBox   | `0 0 32 32`       | favicon の基準が 32px（`LOGO-07`）                                   |
| live area | `4..28`（24 角）  | 外周 4 を余白に残す。`LOGO-06` の clear space をマーク内に先取りする |
| 格子      | 偶数座標          | 16px（1/2 倍）で整数ピクセルに乗る                                   |
| 字画      | 4 = 24 / 6        | 16px で 2px。第 2 世代の線幅 2（16px で 1px）では字が細く読めない    |
| 色数      | 1（currentColor） | 白黒 1 色で始める（`LOGO-07`）                                       |
| 対称軸    | なし              | 実験的で動きがある印象（`LOGO-03`）                                  |

### 削除した variant

2026-09-22 に利用者が 3 案とも却下した。コードは削除し、仮説と軸だけを残す。

- `offset-pair`: 同形の 2 面をずらし、重なりだけを塗る。軸は 2 面の関係（重ね）。
- `chosen-one`: 幅と丈の違う 2 面の片方だけを塗る。軸は 2 面の関係（選択）。
- `split-face`: 1 つの面を非対称な対角で割る。軸は 2 面の関係（分割）。

2026-09-23 に利用者が水の 4 案も却下した。理由は「比喩が合わない」と「文字要素が欲しい」である。

- `reflection`: 水面に載る実体と、√2 で縮んでずれた映り込み。軸は水の表し方（像）。
- `wave-345`: 半径 3, 4, 5 の半円をつないださざ波。軸は水の表し方（波）。
- `ripple-rings`: 隙間を 3 で一定にした波紋。軸は水の表し方（環）。
- `sunken-pair`: 幅と同じ丈で、1:2 の深さまで沈む 2 本の柱。軸は水の表し方（沈）。

2026-09-23 に利用者が第 3 世代から `nu-arches` を方向として選んだ。ほかの 4 案はコードを削除し、仮説と軸だけを残す。

- `n-monogram`: 縦画の天地を字画 1 本分ずらした N。軸は文字だけ。
- `n-pond`: 脚が沼へ浸かる小文字 n。軸は文字 + 沼の形。磁石の読みが残っていた。
- `u-basin`: 底に水をため泡を浮かべた U。軸は文字 + 沼の形。片目の顔の読みが残っていた。
- `cursor-n`: 斜画をポインタにした N。軸は文字 + UI の記号。16px ではポインタに読めなかった。

2026-09-23 に利用者が、溶ける気配と曲線で滑らかなテイストを求めた。角を持つ派生と、溶ける気配と関係しない派生はコードを削除する。

- `nu-slant`: 両端を 45° で平行に切った nu。軸は端点（斜め）。
- `nu-contrast`: 肩と底を字画の半分に細めた nu。軸は字画の強弱。
- `nu-pool`: u の窪みに水をためた nu。軸は要素の追加（水）。
- `nu-bubble`: u の窪みに泡を浮かべた nu。軸は要素の追加（泡）。
- `nu-gap`: n と u の間に隙間を空けた nu。軸は字のつなぎ。
