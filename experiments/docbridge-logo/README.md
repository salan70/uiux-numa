## Problem

DocBridge（`salan70/docbridge`）は Markdown 文書とコードを `@doc` / `@code` の注釈で双方向に結び、乖離を検査する CLI である。
ロゴは無く、README は文字とバッジだけで始まる。
npm と GitHub の一覧では、同種の道具（ESLint、Prettier、typedoc）にマークがあり、DocBridge だけが顔を持たない。

## Target

DocBridge を npm で導入する開発者と、GitHub で README を読む人。
ロゴが出る面は 2 つある。
GitHub README のヘッダ（マークと wordmark の横組み、明暗）と、favicon / npm の avatar（16〜64px の正方形）である。

## Scope / Domains

対象はマーク 1 個と、その lockup の形式である。
domain は `logo-brand-identity`、`visual-design`、`accessibility`。
`logo-brand-identity` を先頭に置き、Catalog に載せない。

比喩、印象、色、使い先は、制作前に利用者が決めた（2026-09-30）。

- 比喩: 橋そのもの。2 つの岸や `@` の記号、文字組ではない。
- 印象: 開発者ツールらしく淡々と。線が細めで幾何学的。
- 色: 単色。黒と白の反転を前提にし、色は後で足す。
- 使い先: GitHub README のヘッダ、favicon / npm のアイコン。

第 1 世代は、橋の構造（アーチ、桁、吊り）と、面か線かの 2 軸を変える。
`arch-solid` を基準にし、`arch-line` は同じ骨格を線で描く。
`beam-solid` と `suspension-solid` は構造だけを変える。

第 2 世代は、利用者が第 1 世代を見て「名前の文字を自然に組み込みたい。D と B が橋の形に近い」と求めた（2026-09-30）。
D と B は bowl がアーチなので、字を 90° 倒して stem を桁、bowl をアーチにする。
変える軸は、文字（D か B か）、倒す向き（bowl が桁の上か下か）、桁の張り出し（bowl と同じ幅か、2 ずつ外へ出すか）の 3 つで、1 案に 1 つずつ割り当てる。

第 3 世代は、利用者が第 2 世代を「方向性いい感じ」とし、「全体的に丸みを帯びさせて」と求めた（2026-09-30）。
第 2 世代の 6 案の骨格を保ち、角に丸みを付ける。変える軸は丸みの有無だけで、id は `<第 2 世代の id>-round`。

第 4 世代は、利用者が第 3 世代を「概ねいい感じ」とし、「数式や幾何学模様で、より美しく」と求めた（2026-09-30）。
bowl が桁の上にある `d-over-round` と `b-over-round` を基準に、作図の体系を 1 つに絞って引き直す。
体系は「線の太さ 4 を単位にし、半径はその倍数（4、8、12）か半分（2）だけにする」である。
変える軸は、D の直線部の有無（`d-arc`）、同心の帯の追加（`d-rings`）、B の線の均一化（`b-even`）の 3 つ。

## Constraints

- `<text>`、`var()`、`aria-labelledby` を使わない。`role="img"` と最初の子 `<title>`、id は `part-mark-<role>`、色は `currentColor`（[SVG ツールチェーンの ADR](../../docs/decisions/2026-09-18-svg-toolchain.md)）。
- 白黒 1 色で成立させる（`LOGO-07`）。色を足すなら part の id の末尾 `-accent` で役割を示し、利用画面の CSS が塗る。
- viewBox は `0 0 32 32`、live area は `4..28`。favicon の基準が 32px である（`LOGO-07`）。
- 面の縁と線の縁は偶数座標に置き、16px で整数ピクセルに載せる（`SVG-01`）。
- wordmark は利用画面の HTML テキストで組む。フォントは未決で、モックは `tokens/typography` の sans を使う。
- Catalog には載せない（[掲載しない Experiment の ADR](../../docs/decisions/2026-09-22-unlisted-experiments.md)）。

## Hypothesis

橋の輪郭だけを面で描けば、名前と結び付き、16px でも読める（`LOGO-01`、`LOGO-02`）。
橋の構造の違いは、意味の読みやすさと最小サイズでの成立を分ける。
アーチは曲線 1 本で橋と読めるが、桁橋は Π や机に、吊橋は 16px で塊になると見込む。

## Variants

| id                 | 仮説                                                  | 変えた軸 | 実装                         |
| ------------------ | ----------------------------------------------------- | -------- | ---------------------------- |
| `arch-solid`       | 基準: 桁とアーチの帯を面で描けば、16px でも橋と読める | —        | `variants/arch-solid/`       |
| `arch-line`        | 同じ骨格を線幅 2 で描くと、淡々とした印象が強まる     | 面か線か | `variants/arch-line/`        |
| `beam-solid`       | 桁と 2 本の橋脚だけの桁橋は、最も少ない要素で橋になる | 橋の構造 | `variants/beam-solid/`       |
| `suspension-solid` | 塔と主索の輪郭は、最も橋らしい形として一目で伝わる    | 橋の構造 | `variants/suspension-solid/` |

### 造形のパラメータ

| 項目      | 値                | 理由                                                     |
| --------- | ----------------- | -------------------------------------------------------- |
| viewBox   | `0 0 32 32`       | favicon の基準が 32px（`LOGO-07`）。keysync-logo と同じ  |
| live area | `4..28`（24 角）  | 外周 4 を余白に残す（`LOGO-06`）                         |
| 格子      | 偶数座標          | 16px（1/2 倍）で整数ピクセルに載る（`SVG-01`）           |
| 桁の厚み  | 4                 | 16px で 2px。線幅 2 の `arch-line` は 1px                |
| 橋脚の幅  | 4                 | 桁と同じ重さにし、要素の太さを 1 種類にする（`FORM-03`） |
| 端点と角  | butt、miter       | 幾何学的で淡々とした印象。丸めない                       |
| 対称軸    | 縦 1 本           | 落ち着きと信頼に合わせる（`LOGO-03`）                    |
| 色数      | 1（currentColor） | 反転前提の単色（利用者の指定、`LOGO-07`）                |

### 座標の導出

`arch-solid`

| 対象         | 体系                                        | 理論値 | 採用値 | 誤差 | 理由                                                          |
| ------------ | ------------------------------------------- | ------ | ------ | ---- | ------------------------------------------------------------- |
| 桁           | live area の上端から厚み 4                  | 4..8   | 6..10  | +2   | 全体（桁の上端から脚の下端）を 6..26 に置き、中心を 16 にする |
| アーチの外径 | 桁の下端に頂点が接し、脚が live area の両端 | 12     | 12     | 0    | 中心 (16,22)。頂点 10 = 桁の下端                              |
| アーチの内径 | 帯の厚みを桁と同じ 4 にする                 | 8      | 8      | 0    | 開口の幅 16、高さ 8。16px で 8×4px                            |
| 脚の下端     | live area の下端                            | 28     | 26     | −2   | 上端 6 と対称にし、視覚的な中心を 16 に置く                   |

`arch-line`

| 対象         | 体系                                 | 理論値 | 採用値 | 誤差 | 理由                                    |
| ------------ | ------------------------------------ | ------ | ------ | ---- | --------------------------------------- |
| 桁の中心線   | 縁 6..8 が偶数に載る                 | 7      | 7      | 0    | 線幅 2 は中心線を奇数に置く（`SVG-01`） |
| アーチの半径 | 外縁が `arch-solid` の外径 12 と一致 | 11     | 11     | 0    | 中心 (16,20)。上縁 8 が桁の下縁に接する |
| 脚の中心線   | 縁 4..6 と 26..28                    | 5, 27  | 5, 27  | 0    | live area の両端                        |

`d-over`

| 対象        | 体系                          | 理論値 | 採用値 | 誤差 | 理由                                   |
| ----------- | ----------------------------- | ------ | ------ | ---- | -------------------------------------- |
| stem（桁）  | `arch-solid` の桁を下端へ移す | 22..26 | 22..26 | 0    | 厚み 4 を保つ                          |
| bowl の外径 | `arch-solid` のアーチと同じ   | 12     | 12     | 0    | 中心 (16,18)。直線部 18..22 の上に半円 |
| bowl の内径 | 帯の厚みを 4 にする           | 8      | 8      | 0    | 開口の幅 16、高さ 12                   |

`d-under` は `d-over` を y = 16 で上下に反転した。
`d-over-span` は桁を 4..28 に残し、bowl を外径 10、内径 6（中心 16,18）に縮めて 2 ずつ張り出す。
`b-over` は桁を `d-over` と同じにし、bowl を外径 13、帯 3 の 2 個（中心 x 10.5 と 21.5、直線部 13..22）で中央 15..17 を重ねた。帯 3 は 16px で 1.5px になり、内縁が奇数座標に載る。偶数の帯 4 では開口が 4 になり、16px で読めないため帯 3 を選んだ。
`b-under` は `b-over` を上下に反転し、`b-over-span` は bowl を外径 11、帯 3 に縮めて桁を 2 ずつ張り出した。

第 3 世代の丸み

| 対象                    | 体系                                      | 理論値 | 採用値 | 誤差 | 理由                                                                                                                         |
| ----------------------- | ----------------------------------------- | ------ | ------ | ---- | ---------------------------------------------------------------------------------------------------------------------------- |
| 桁の端の角              | 厚み 4 の半分で端を半円にする             | 2      | 2      | 0    | `span` 以外。張り出しの無い端を pill にする                                                                                  |
| 開口の下の角            | 桁の端と同じ                              | 2      | 2      | 0    | B の開口（幅 7 と 5）でも平らな辺が残る                                                                                      |

| B の弧の交点の谷        | 2 つの bowl の外弧に外接する円            | 1.5    | 1.5    | 0    | 接点は `b-over-round` が (14.97, 8.28)、`b-over-span-round` が (15.04, 8.79)。1 では谷が残り、2 では bowl の頂が平らに見える |

第 4 世代の作図

`beam-solid` と `suspension-solid` は桁と橋脚の値を `arch-solid` から引き継ぎ、橋脚は桁から 4 内側（8..12、20..24）に立てた。
`suspension-solid` の主索は塔の頂 (10,7) と (22,7) を二次曲線で結び、制御点 (16,30) で桁の上端 18 に触れる。
