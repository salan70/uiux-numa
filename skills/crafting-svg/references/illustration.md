# イラスト

UI 内のイラスト（空状態、オンボーディング、hero）の項目。
共通の造形は `skills/crafting-svg/references/foundations.md` にある。

- `ILLUS-01` 文言の補助であり、代替ではない: 空状態の説明と次の操作を文言で先に確定し、理解を助ける絵だけ残す。
- `ILLUS-02` 文言を絵で繰り返さない: 単一の比喩で 1 つの概念だけ描く。配置は見出し、イラスト、説明と操作の順。
- `ILLUS-03` 空状態の絵は控えめで中立にする: 背景に近い明度の淡い単色にし、押せるように見せない。祝福や初回だけ色付きを許す。
- `ILLUS-04` エラーの空状態で遊ばない: 既定は警告のアイコン。文言で原因と復帰の手段を示す。
- `ILLUS-05` 支配的な要素は 1 つ、強調は 3 段階まで。
- `ILLUS-06` 明暗で焦点と奥行きを作る: 主役に最大の明暗差を集め、背景は明るく低彩度にする。
- `ILLUS-07` 視線を文言と操作へ導く: 主役は幾何学的な中心のやや上に置き、線や視線の向きを文言側へ揃える。
- `ILLUS-08` 線幅、角丸、比率、パレットを 1 組で揃える: 類似色 2〜3 色相。キャラクターは背景に線画で置き、なくても意味が通るようにする。

装飾のイラストは `alt=""` か `aria-hidden="true"` にする（`UIFIT-05`）。
