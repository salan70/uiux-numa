# UI への適合とアクセシビリティ

SVG を画面に置くときの項目。手順 1 と手順 4 で参照する。

- `UIFIT-02` 意味を担う図形は 3:1 以上: 単色アイコンは全体を 1 つの図形として測る。四捨五入しない。
- `UIFIT-04` 単独で意味を持つ SVG は `role="img"` と最初の子 `<title>` で名前を付ける: `aria-labelledby` は使わない（最適化で `title` の id が消える）。書き出しツールが残す `<title>` は削除する。
- `UIFIT-05` 装飾と、可視テキストを持つボタン内の SVG は `aria-hidden="true"` と `focusable="false"` で隠す: 名前は要素側の可視テキストか `aria-label` で与える。
- `UIFIT-07` 単色は `currentColor` で継承させる: forced-colors は SVG の固定色を調整しない。多色は利用画面の CSS で `#part-*` を上書きし、SVG 内で `var()` を使わない。多色のイラストはブラウザの forced-colors エミュレーションで確かめる。
- `UIFIT-10` 同じプロダクト内で寸法、線幅、角、端点、細部の量、遠近を統一する: 外部のアイコン集を混ぜず、既存の組と並べて比較する。

Carbon はアイコンに 4.5:1 と 44px を求める。WCAG 2.2 の 3:1 と 24px より厳しいそのシステムの値である。
