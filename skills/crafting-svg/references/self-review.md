# 自己確認

手順 4 で、描画した画像を読んで確認する。
判定は制作者の自己確認であり、採用の判断には使わない。

## 確認の入力

- 比較シート（`just svg-sheet`）: 実利用サイズを含む複数サイズ、明暗の背景、最小サイズの 4 倍拡大
- 利用画面の撮影（`just web-shot`）
- 既存の基準があれば同じシートに並べる

## 見た目の観察（造形）

判定は 良い / 許容 / 課題あり の 3 段階。観察したことと、該当する asset とサイズを書く。

| 項目           | 観察の仕方                                                      | 参照                  |
| -------------- | --------------------------------------------------------------- | --------------------- |
| 見かけの大きさ | 組の中で 1 つだけ大きく、または小さく見えないか                 | `ICON-06`、`FORM-02`  |
| 線幅と重さ     | 組の中で 1 つだけ太く、または細く見えないか。水平線が重くないか | `FORM-03`、`FORM-06`  |
| 端点と角       | cap と join が統一されているか。鋭角が切れていないか            | `ICON-07`、`SVG-02`   |
| 視覚的な中心   | 見た目で中央に置かれているか                                    | `FORM-01`             |
| 細部の量       | 最小サイズで判別できない要素や潰れた隙間がないか                | `FORM-04`、`ICON-08`  |
| ピクセルの整列 | 4 倍拡大で線がぼやけていないか                                  | `ICON-09`、`SVG-01`   |
| 曲線の質       | 接続点が折れて見えないか                                        | `FORM-11`             |
| 単色での成立   | 明暗どちらの背景でも形が読めるか                                | `FORM-08`、`UIFIT-07` |
| 既製感         | 有名なアイコン集の形をなぞっていないか。固有の要素があるか      | `LOGO-04`、`FORM-04`  |

## UX 上の観察（意味と適合）

| 項目         | 観察の仕方                                                           | 参照                   |
| ------------ | -------------------------------------------------------------------- | ---------------------- |
| 意味の伝達   | ラベルを隠して意味を推測できるか。比喩が既知の対応か                 | `ICON-02`              |
| 識別         | 組の中で取り違えないか。16px で見分けられるか                        | `ICON-03`、`ICON-11`   |
| 主従関係     | 利用画面でアイコンが文字より目立っていないか                         | `UIFIT-10`             |
| コントラスト | 意味を担う図形が隣接色に 3:1 以上か                                  | `UIFIT-02`             |
| 名前と役割   | `role="img"` と `<title>`、または `aria-hidden` が用途に合っているか | `UIFIT-04`、`UIFIT-05` |

意味の伝達と識別は自己確認では確かめきれない。
Brief を知らない別の agent か人にラベルなしのシートを見せた結果は、ユーザーテストではないので仮説として記録する。
ラベルなしで見せるときは、名前を伏せた別の描画を作るか、順序を入れ替えて名前との対応を切る。

## 記録の形式

反復ごとに次を残し、README の反復の記録の表に写す。

```text
round N
- 観察: <項目>: <観察したこと>（<asset>、<サイズ>、<シート名>）
- 変更: <part-id> の <何を> <どう>
- 参照: <知識 ID>
- 終了理由: 指摘なし | 上限到達 | 画像を読めない
```

## 終了条件

- 見た目と UX の両方で「課題あり」が残っていなければ終了する。「許容」は理由を書いて残してよい。
- 反復は 1 variant あたり 3 回まで。上限に達したら未解決の項目を報告する。
- 画像を読めない項目は未検証として報告する。推測で判定しない。
