# ロゴ

シンボルマークと wordmark の項目。共通の造形は `skills/crafting-svg/references/foundations.md` にある。
wordmark は path で描くか、利用画面の HTML テキストで組む（`<text>` は使わない）。

- `LOGO-01` 核となる要素 1 つを面で表す: 細い線と鋭角は縮小で潰れる。文字は原則入れない。
- `LOGO-02` 無名ブランドでは扱う対象を示す: 新規の個人開発では抽象図形だけにせず、対象を想起させる要素を 1 つ入れる。「ロゴは事業内容を説明しなくてよい」より、こちらを優先する。
- `LOGO-03` 対称性を性格に合わせる: 非対称は刺激的な性格に合い、落ち着きや信頼には効かない。
- `LOGO-04` 単純にしすぎない: 円と正方形だけの汎用図形にせず、識別の手がかりになる固有の要素を 1 つ残す。
- `LOGO-06` clear space と最小サイズを数値で定める: 単位はマーク自身の寸法にする（Spotify はアイコン高さの 1/2、最小はロゴ 70px、アイコン 21px）。自分のプロダクトでは単位を決め直す。
- `LOGO-07` 白黒 1 色で設計を始める: 反転と切手サイズで成立してから色を加える。縮小時は横組み、縦積み、マーク単独の段階を用意し、favicon は 32px 基準で 16px が崩れるなら専用版を作る。
- `LOGO-08` 負の空間にも形を与える: 負の形を独立した図として抜き出し、単独で読めるか確かめる。
- `LOGO-10` 黄金比の作図を根拠にしない: 作図線は説明用。見た目の重さが揃わないなら作図より視覚的な補正を優先する。
