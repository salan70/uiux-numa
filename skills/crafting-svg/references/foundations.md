# 共通の造形

アイコン、ロゴ、イラストに共通する項目。
記録とレビューでは ID で引用する。欠番は削除した項目である。
数値はこのリポジトリで採った値か、出典のシステムの値であり、普遍の正解ではない。

- `FORM-01` 視覚的な中心に置く: 重さが偏る図形は、24px と 16px で描画して見た目で中央になるまで 0.5px 刻みで動かす。
- `FORM-02` 円と尖った形は少し大きくする: 正方形と並ぶ円は一回り大きく描く（Material 1 の keyline は正方形 18、円 20）。
- `FORM-03` 見かけの重さを揃える: 1 組で stroke-width を統一し、重く見える形は面積で調整する。
- `FORM-04` 本質だけに削る: 16px で判別できない細部を消す。
- `FORM-06` 水平線は太く見える: 等しく見せるなら水平線だけ 5〜10% 細くして描画で判断する。
- `FORM-08` 単色で成立させてから色を足す: 黒 1 色で意味が区別できる形にする。意味を持つ図形は隣接色と 3:1 以上。
- `FORM-09` 大きさの差で重要度を示す: 最重要の要素を最大にし、中心軸の両側で視覚的な量を揃える。
- `FORM-10` 近接、類同、閉合を使う: 群にする要素だけ近づける。輪郭の欠けは 1 か所にとどめる。
- `FORM-11` 曲線の接続で接線を揃える: 極点にノードを置き、`A` と `L` の接続点で接線を一致させる。

## 注意点

- 角度の規則（IBM は 45° と 15° 刻み）は 1 組ごとに決める。
- `FORM-03` と小サイズの細線化は衝突する。例外は密な形に限り、記録に残す。
- 黄金比や既存システムの数値は説明と一貫性の道具であり、品質の根拠にしない（`LOGO-10`）。
